## 🌟 The Vision

> **LAMINAR** is building the AI operating system for future cities. We are transforming passive surveillance into **predictive, autonomous, and human‑centered urban intelligence**. 

By fusing real‑time computer vision, predictive analytics, large language models, and immersive 3D visualizations into a single, ultra‑responsive platform, Laminar delivers unprecedented situational awareness and operational command. *(Powered entirely by **Google Gemini API** and **Groq API** for maximum inference speed and reasoning).*

## ⚙️ Quick Start

### 📋 Prerequisites
- Python 3.10+
- Node.js 20+
- PostgreSQL Server

### 🛠️ 1. Clone & Setup
```bash
git clone https://github.com/bhargavatejagolla/Laminar.git
cd Laminar
```

### 🚀 2. Unified Startup
Laminar includes smart startup scripts that automatically clear stale processes (ports 3000/8000) and initialize both the backend and frontend simultaneously.

**Windows**
```cmd
start.bat
# or via Python directly:
python start.py
```

**Linux/macOS**
```bash
./start.sh
```

### 🌐 3. Access the Platform
- **Dashboard:** [http://localhost:3000](http://localhost:3000)
- **API Documentation:** [http://localhost:8000/docs](http://localhost:8000/docs)
