# Security Policy

## Supported Versions

Laminar is currently in active development. Security updates are provided for the latest stable release.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Security is a top priority for Laminar as an autonomous smart city OS. 

If you discover a security vulnerability within Laminar, please send an e-mail to Golla Bhargava Teja at your earliest convenience instead of opening a public issue. We will review all security vulnerabilities within 48 hours and work with you to resolve the issue as quickly as possible.

**Response Process:**
1. Acknowledge receipt of your vulnerability report within 48 hours.
2. Provide an estimated timeline for the fix.
3. Notify you when the vulnerability is patched.

Thank you for helping keep Laminar secure!
